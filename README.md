# Ranger Shield

A cybersecurity readiness assessment tool built for small businesses that don't have dedicated IT or security staff.

## What it does

Ranger Shield walks a business owner through 37 questions mapped to the **NIST Cybersecurity Framework 2.0** and **CIS Controls v8**. Based on the answers, it generates:

- A risk level and prioritized findings
- Plain-language help for every question: what it means, how to check it, and why it matters
- A downloadable PDF report

The goal is to help business owners who don't have a technical background self-identify real security and compliance gaps, before those gaps turn into a costly incident.

## Built with

- React
- TypeScript
- Vite
- Tailwind CSS

## Status

This is an active, evolving project. Core assessment, scoring, plain-language guidance, and PDF export are functional. A planned AI guide will explain findings and walk owners through fixes.
